# B-087 — Longer sequencer clips cut short with multiple sequencers

Report ID: B-087  
Status: open  
Severity: see  
Source: user 2026-09-30  

## User symptom

Longer sequencer clips get cut short when a patch has two or more sequencers.

## Repro

Use a patch with two or more sequencers and a longer clip. Play the patch and observe that the clip ends before its intended length.

## Expected behavior

Longer clips should play for their authored length regardless of whether the patch contains one sequencer or multiple sequencers.

## Notes

No cause has been investigated or confirmed. Do not treat a possible cause as fact.

## Investigation / fix shape

Not started. Do not fix in this report. This is a docs-only bug report; no code change is included.
